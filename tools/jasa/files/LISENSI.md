# Lisensi Pemakaian Zuno Studio

Pemberi lisensi: Nexamind (Creative @nexamind.ai), kontak: [ISI kontak penjual].
Penerima lisensi: pembeli yang tercatat pada bukti pembelian.

Dengan memasang atau memakai Zuno Studio, penerima lisensi setuju dengan ketentuan berikut.

## Yang boleh
1. Memasang dan memakai Zuno Studio untuk **satu brand atau satu usaha** milik penerima lisensi.
2. Mengubah pengaturan brand, isi konten, dan tampilan untuk kebutuhan sendiri.
3. Membuat salinan (fork) pribadi yang dipakai untuk memasang web ini dan menerima pembaruan.
4. Memakai hasil kerja web ini secara komersial (konten, gambar, naskah, aplikasi buatan tab Agent Builder). Hasil itu milik penerima lisensi.

## Yang tidak boleh
1. Menjual, menyewakan, membagikan, atau mengunggah ulang kode Zuno Studio, baik utuh maupun sebagian, kepada pihak lain.
2. Memasang Zuno Studio untuk brand atau usaha orang lain tanpa lisensi tambahan.
3. Membuat repo salinan menjadi publik.
4. Menghapus keterangan lisensi ini dari repo.

## Komponen pihak ketiga
- Folder `.claude/skills` dan `.claude/agents` berisi skill sumber terbuka milik pihak lain (MIT atau Apache-2.0). Bagian itu **tetap tunduk pada lisensi aslinya** (file LICENSE di tiap folder), bukan pada ketentuan "Yang tidak boleh" di atas. Daftar dan sumbernya: `.claude/skills/README.md`.
- Skill yang lisensi sebagian isinya tidak bisa dipastikan untuk dijual ulang (taste-skill, ui-styling) tidak ikut paket. Cara memasangnya sendiri ada di `PANDUAN-LOKAL.md` bagian 6; pemakaiannya mengikuti lisensi sumber masing-masing.
- Claude Code dipasang dari installer resmi Anthropic dan dipakai dengan akun Claude atau API key milik penerima lisensi sendiri, mengikuti ketentuan Anthropic.

## API key dan biaya
- Penerima lisensi memakai API key AI, akun Vercel, dan akun GitHub miliknya sendiri.
- Biaya pemakaian AI dan hosting menjadi tanggungan penerima lisensi.
- Pemberi lisensi tidak menyimpan dan tidak pernah meminta API key penerima lisensi.

## Tanggung jawab
- Zuno Studio diberikan sebagaimana adanya. Hasil AI bisa keliru: penerima lisensi wajib memeriksa konten dan aplikasi sebelum dipublikasikan.
- Pemberi lisensi tidak bertanggung jawab atas kerugian akibat pemakaian, termasuk biaya AI, pemblokiran akun platform, atau isi yang diterbitkan penerima lisensi.

## Pembaruan dan dukungan
- Pembaruan disalurkan lewat repo penjual. Penerima lisensi menariknya sendiri dengan Sync fork (lihat PANDUAN.md).
- Lama dan bentuk dukungan mengikuti kesepakatan pembelian: [ISI masa dukungan].

## Berakhirnya lisensi
Lisensi berakhir bila penerima lisensi melanggar ketentuan "Yang tidak boleh". Setelah itu, akses ke repo penjual dapat dicabut.
